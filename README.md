Одностраничный сайт для магазина "Только раз в году".

## Функциональность

- Каталог товаров из data-файла (js/products.js)
- Корзина с подсчётом суммы каждой позиции и общего итога
- Изменение количества: кнопки +/− и ручной ввод
- Сохранение корзины в localStorage
- Оформление заказа через mailto (готовое письмо с составом)
